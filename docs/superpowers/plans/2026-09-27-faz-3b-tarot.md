# Faz 3b: Günlük Tarot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Her gün kadın ve erkek için ayrı bir **tarot** carousel'i üretmek (günlük paket 4 gönderi, pazartesi 6). Carousel kapak, 12 tarot slaytı ve kapanıştan oluşur ve kendi müzikli Reels'i vardır. Her burca günün tek kartı çekilir; 78 kart koddan çizilen minimal bir tasarım sistemiyle görselleşir. Kartlar gönderinin tamamı için ya da tek burç için yeniden çekilebilir.

**Architecture:**
- **Üretim:** Tarot, `GenerationSpec` katmanına üçüncü tür olarak girer (`TAROT_SPEC`). Günlük burçla aynı JSON şemasını, kalite kapısını, sürümlemeyi, düzenlemeyi ve arşivi kullanır; kart `meta.tarotCardId`'de saklanır.
- **Slayt verisi:** Tarot slaytları mevcut `sign` slayt verisine isteğe bağlı `tarotCard` alanı eklenerek taşınır. Düzenleyici, taslak ve indirme yolları değişmez.
- **Şablon:** Görünüm yeni `pastel-tarot@1` şablonudur.
- **Reels:** Dondurulmuş Reels sahneleri varsayılanı değişmeyen parametrelerle yeniden kullanılır. Günlük Reels altın testi aynen geçmelidir.

**Tech Stack:** Mevcut yığın; yeni paket yok.

**Spec:** `docs/superpowers/specs/2026-09-25-burc-studio-design.md`: §1.3 Tarot, §1.5 Tarot, §3 TarotSlide ve tarot tasarım sistemi, §5 "kartları yeniden çek".

## Global Constraints

- **Tarot çekilişi (spec §1.5):** Her gün, her kitle için deste `crypto` ile karıştırılır, ilk 12 kart sırayla 12 burca atanır, tekrar olmaz. Yalnızca düz kart.
- **Yeniden çekme (spec §1.5):** "Kartları yeniden çek" yeni sürüm oluşturur. Tüm gönderi için 12 kartı birden ya da tek bir burcun kartını diğer 11 kartı dışarıda bırakarak yeniden çeker.
- **Metin:** Tarot yorumu günlük sınırlarla (`DAILY_LIMITS`: yorum 280–420). Kart adı metinde geçebilir ve geçmelidir; haftalıktaki yasak tarota uygulanmaz.
- **Görsel sistem (spec §3):**
  - 22 Büyük Arkana ikonu, 4 takım sembolü, As–10 için pip yerleşimi ve 4 saray işareti.
  - Bu parçalardan 78 kart sistematik olarak çizilir.
  - Tek çizgi stili ve pastel palet.
  - Tarayıcı render kısıtları geçerli: SVG konumlu div içinde, inline stil, `Math.round` ile tam piksel.
- **Sürümler:** Şablon `pastel-tarot@1`, prompt `tarot-v1`, dosya eki `tarot` (mevcut), zemin kaydırması `KIND_OFFSETS.tarot = 1` (mevcut).
- **Dondurulmuş klasörler:** `pastel-v1/` ve `pastel-v1-reels/` yalnızca varsayılanı mevcut davranışı koruyan parametrelerle değişir. Günlük kart ve Reels altın testleri değişmeden geçer.
- **Kullanıcı kararları:** Yerel model yok. Tüm akış otomatik, manuel adım yok. Reels müziği kodla üretilir.

## Review Focus

1. **Tek burç yeniden çekme:** Çekilen yeni kart diğer 11 karttan biriyle aynı olmamalı. Haftalık tek burç yenilemede de mevcut kartlarla çakışma olmamalı. → Task 2 çekiliş testi, Task 3 servis testi.
2. **Pazartesi yükü:** Cron 6 gönderiyi paralel üretir; biri kotaya takılırsa diğerleri yine üretilmeli. Tarot kalemleri plana göre eklenmeli. → Task 4 cron testi.
3. **Mevcut canlı ayarlar:** Canlıdaki `dailyPlan` yalnız burç içerir. Tarot, ayarlardan açılmadan cron'a girmemeli; canlıya alma adımında plan güncellenmeli. → Task 4 ve Task 8.
4. **En uzun tarot yorumu (420 grafem) ve en uzun kart adı ("Tılsım Kraliçesi", "Değnek Şövalyesi"):** Kartta kırpılmadan sığmalı. → Task 6 E2E ve görsel kontrol.
5. **Arşivden yeniden üretim:** Eski tarot sürümü kendi kartlarıyla birebir aynı çizilmeli. → Task 5 altın testi.

```ts
import { createElement } from 'react';
import { renderToStaticMarkup } from 'react-dom/server';
import { describe, expect, it } from 'vitest';
import { TAROT_DECK } from '@/lib/tarot/deck';
import { ROMAN, TarotCardArt } from './tarot-card';
import { pipLayout } from './pips';

describe('tarot tasarım sistemi', () => {
  it('pip yerleşimi 1–10 için doğru sayıda, kutu içinde ve alt yarısı ters pip verir', () => {
    for (let count = 1; count <= 10; count++) {
      const pips = pipLayout(count);
      expect(pips).toHaveLength(count);
      expect(pips.every((pip) => pip.x > 10 && pip.x < 90 && pip.y > 5 && pip.y < 95)).toBe(true);
      expect(pips.every((pip) => pip.flip === pip.y > 50)).toBe(true);
    }
  });

  it('78 kartın her biri çizilir; etiket, ad ve motif türü doğru', () => {
    for (const card of TAROT_DECK) {
      const html = renderToStaticMarkup(createElement(TarotCardArt, { cardId: card.id, width: 300 }));
      expect(html).toContain(card.name.toLocaleUpperCase('tr-TR'));
      expect(html).toContain(`data-card="${card.id}"`);
    }
    const art = (id: string) => renderToStaticMarkup(createElement(TarotCardArt, { cardId: id, width: 300 }));
    expect(art('yildiz')).toContain('>XVII<');
    expect(art('deli')).toContain('>0<');
    expect(art('kupa-7').split('data-pip=').length - 1).toBe(7);
    expect(art('tilsim-kralice')).toContain('data-court="kralice"');
    expect(art('kilic-as')).toContain('>AS<');
    expect(ROMAN[21]).toBe('XXI');
  });

  it('büyük arkananın 22 ikonu birbirinden farklıdır', () => {
    const icons = TAROT_DECK.filter((card) => card.arcana === 'buyuk').map((card) =>
      renderToStaticMarkup(createElement(TarotCardArt, { cardId: card.id, width: 300 })).match(/data-icon="[^"]+"[\s\S]*?<\/svg>/)?.[0],
    );
    expect(new Set(icons).size).toBe(22);
  });
});
```
