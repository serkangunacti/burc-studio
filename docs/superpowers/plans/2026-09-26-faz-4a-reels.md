# Faz 4a: Carousel'den Reels — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Her günlük burç gönderisini (kadın ve erkek ayrı) Instagram Reels'e hazır, yaklaşık 59 saniyelik, müziksiz, 1080×1920 bir MP4'e dönüştürmek. Video, gönderi sayfasında önizlenir, tarayıcıda üretilir, indirilir ya da telefonda paylaşılır.

**Architecture:**
- Reels, `pastel@1` şablon ailesinin 9:16 kardeşi olarak yazılır (`src/remotion/templates/pastel-v1-reels/`). Zeminler, fontlar, burç çizimleri ve renk token'ları, dondurulmuş `pastel-v1` modüllerinden salt okunur import edilir.
- Sunucu, gönderi sürümünden kendi kendine yeten bir `ReelsProps` kurar: kapak bilgisi ve 12 burcun başlık, **kısa metin**, puan ve şans verileri.
- İstemci aynı veriyi `@remotion/player` ile önizler ve `@remotion/web-renderer` `renderMediaOnWeb` ile H.264 MP4'e çevirir (WebCodecs).
- Kullanıcı kararları (26.09.2026):
  - Her carousel'e ayrı bir Reels.
  - Reels'e özel dikey sahneler.
  - Şimdilik müzik yok.
  - Bu faz, yol haritasında tarottan (Faz 3) önceye alındı.

**Tech Stack:** Faz 2 yığını + `@remotion/transitions` 4.0.529 (`TransitionSeries`, `fade`, `linearTiming`), `remotion` (`interpolate`, `spring`, `useCurrentFrame`), `@remotion/web-renderer` (`renderMediaOnWeb`, `canRenderMediaOnWeb`).

**Spec:** `docs/superpowers/specs/2026-09-25-burc-studio-design.md` (§3 Reels, §4 Video, §5 `/gonderi` indirme menüsü, Faz 4 satırı)

## Global Constraints

- Faz 0–2'nin tüm Global Constraints maddeleri geçerli. Kompozisyonlarda yalnızca satır içi stil kullanılır; `z-index`, `backdrop-filter`, `mix-blend-mode`, CSS `filter` ve `text-transform` yoktur.
- Çalışma dalı `faz-4a-reels`, başlangıç noktası `main` (57180ca).
- Video biçimi: 1080×1920, 30 fps, MP4 (H.264), ses yok (`muted: true`).
- Zaman çizelgesi:

  | Sahne | Kare |
  |---|---|
  | Giriş | 75 |
  | Her burç | 150 |
  | Kapanış | 90 |
  | Sahneler arası geçiş (her biri) | 15 (`fade`) |

  12 burçla toplam 1770 kare, yani **59,0 saniye**.
- Güvenli alan: Instagram Reels arayüzü üstte yaklaşık 250 px'i, altta yaklaşık 420 px'i, sağda yaklaşık 130 px'i kapatır.
  - Önemli içerik y 260–1500, x 80–960 aralığında kalır.
  - Filigran alttan 420 px yukarıdadır.
- Animasyonlar yalnızca `useCurrentFrame` tabanlıdır. Konum değerleri tam piksele yuvarlanır (çıktının belirleyici olması için).
- Kısa metin (`short`, en fazla 140 grafem), Faz 1 kalite kapısından geçmiş alandır. Reels uzun yorumu göstermez.
- Dosya adı: `YYYY-MM-DD_<kitle>-burc_reels.mp4`.
- Reels, gönderinin `templateVersion` değeriyle seçilir (`getTemplate(v).Reels`). Onaydan sonra `pastel-v1-reels/` klasörü `pastel-v1` gibi SHA-256 manifestiyle dondurulur.
- Render her zaman kayıtlı sürümü kullanır. Kaydedilmemiş değişiklik varken Reels üretimi kapalıdır.

```ts
export function reelsDurationInFrames(signCount: number): number {
  const sceneCount = signCount + 2;
```

```ts
import { toReelsSign } from '@/remotion/reels';
import type { BrandProps, ReelsProps } from '@/remotion/slide-types';
import type { PostDetail } from './repository';
import { buildSlideProps } from './slide-props';

export function buildReelsProps(detail: PostDetail, brand: BrandProps): ReelsProps {
  const slides = buildSlideProps(detail, brand);
  const [cover] = slides;
  if (cover?.slide.type !== 'cover') throw new Error('Gönderinin ilk slaytı kapak olmalı');
  const shortBySign = new Map(detail.slides.flatMap((slide) => (slide.reading ? [[slide.reading.sign, slide.reading.short] as const] : [])));
  return {
    audience: cover.slide.audience,
    dateLabel: cover.slide.dateLabel,
    hook: cover.slide.hook,
    brand,
    variant: cover.variant,
    signs: slides.flatMap((props) => (props.slide.type === 'sign' ? [toReelsSign(props.slide, shortBySign.get(props.slide.sign) ?? '')] : [])),
  };
}
```

```ts
import { interpolate, spring } from 'remotion';

const CLAMP = { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' } as const;

export function enter(frame: number, fps: number, delay: number, distance = 40): { opacity: number; transform: string } {
  const progress = frame < delay ? 0 : spring({ frame: frame - delay, fps, config: { damping: 200 } });
  return { opacity: progress, transform: `translateY(${Math.round((1 - progress) * distance)}px)` };
}

export function drawProgress(frame: number, start: number, end: number): number {
  return interpolate(frame, [start, end], [1, 0], CLAMP);
}
```

```ts
// MP4 kutularından süreyi (mvhd) ve görüntü izinin ölçüsünü (tkhd) okur.
export function mp4Info(bytes: Uint8Array): { durationSeconds: number; width: number; height: number } {
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  const type = (offset: number) => String.fromCharCode(...bytes.subarray(offset, offset + 4));
  let durationSeconds = 0;
  let width = 0;
  let height = 0;
  const walk = (start: number, end: number) => {
    let offset = start;
    while (offset + 8 <= end) {
      let size = view.getUint32(offset);
      let header = 8;
      if (size === 1) {
        size = Number(view.getBigUint64(offset + 8));
        header = 16;
      } else if (size === 0) {
        size = end - offset;
      }
      const box = type(offset + 4);
      const body = offset + header;
      if (box === 'moov' || box === 'trak') walk(body, offset + size);
      if (box === 'mvhd') {
        const version = bytes[body];
        const timescale = view.getUint32(body + (version === 1 ? 20 : 12));
        const duration = version === 1 ? Number(view.getBigUint64(body + 24)) : view.getUint32(body + 16);
        durationSeconds = duration / timescale;
      }
      if (box === 'tkhd') {
        const trackWidth = view.getUint32(offset + size - 8) >> 16;
        const trackHeight = view.getUint32(offset + size - 4) >> 16;
        if (trackWidth > 0) {
          width = trackWidth;
          height = trackHeight;
        }
      }
      offset += size;
    }
  };
  walk(0, bytes.length);
  return { durationSeconds, width, height };
}
```

```ts
import { REELS_FPS, REELS_SIZE, reelsDurationInFrames } from '@/remotion/reels';
import type { ReelsProps } from '@/remotion/slide-types';
import { getTemplate } from '@/remotion/templates';

export const REELS_UNSUPPORTED = "Bu tarayıcı video üretemiyor. Bilgisayarda Chrome ya da iPhone'da Safari 26 ve üstünü kullan.";

export async function checkReelsSupport(): Promise<{ ok: true } | { ok: false; reason: string }> {
  if (typeof VideoEncoder === 'undefined') return { ok: false, reason: REELS_UNSUPPORTED };
  const { canRenderMediaOnWeb } = await import('@remotion/web-renderer');
  const result = await canRenderMediaOnWeb({ ...REELS_SIZE, container: 'mp4', videoCodec: 'h264', audioCodec: null, muted: true });
  return result.canRender ? { ok: true } : { ok: false, reason: REELS_UNSUPPORTED };
}

export async function renderReelsMp4(input: {
  templateVersion: string;
  reels: ReelsProps;
  signal?: AbortSignal;
  onProgress?: (progress: number) => void;
}): Promise<Blob> {
  const { renderMediaOnWeb } = await import('@remotion/web-renderer');
  const template = getTemplate(input.templateVersion);
  await template.waitForFonts();
  const result = await renderMediaOnWeb({
    composition: {
      id: 'reels',
      component: template.Reels,
      durationInFrames: reelsDurationInFrames(input.reels.signs.length),
      fps: REELS_FPS,
      width: REELS_SIZE.width,
      height: REELS_SIZE.height,
      defaultProps: input.reels,
    },
    inputProps: input.reels,
    container: 'mp4',
    videoCodec: 'h264',
    muted: true,
    signal: input.signal ?? null,
    onProgress: ({ progress }) => input.onProgress?.(progress),
    // Tek kişilik, ticari olmayan kullanım Remotion'un ücretsiz lisansına girer (spec §12).
    licenseKey: 'free-license',
  });
  return result.getBlob();
}
```

```tsx
  const [running, setRunning] = useState(false);
  const [progress, setProgress] = useState(0);

  const [error, setError] = useState<string | null>(null);
  const durationInFrames = reelsDurationInFrames(reels.signs.length);

    let active = true;

      .then((result) => active && setSupport(result))
      .catch(() => active && setSupport({ ok: false, reason: 'Video desteği denetlenemedi; sayfayı yenile.' }));
```
